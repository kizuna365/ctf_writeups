# CTF Writeups

2020年から現在にかけて取り組んだ CTF の pwn 問題のsolve スクリプト集。

## 構成

| ディレクトリ | 内容 |
|---|---|
| `2020/` ~ `2026/` | 各年の CTF 別 solve スクリプト |
| `all/` | 特定年に紐付かない練習問題・学習用スクリプト |



## スクリプトについて

- pwntools をベースにした exploit スクリプトのみを管理している
- 自分が書いたscriptの特徴があるものを抽出している
- 古いものは環境依存で動作しない可能性がある（あくまで軌跡として参照）
- 未完成のスクリプトが含まれている可能性がある
